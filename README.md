# 🎉 New Year Countdown

A simple and responsive **New Year Countdown** web application that shows the remaining time until the New Year.

## ✨ Features

* ⏳ Real-time countdown
* 📅 Displays days, hours, minutes, and seconds
* ⚡ Updates automatically every second
* 📱 Responsive design
* 🎨 Simple and clean user interface
* 🎊 Displays a message when the countdown ends

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📸 Preview

The application provides a live countdown timer with a simple and user-friendly interface.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.
3. Open `index.html` in your browser.
